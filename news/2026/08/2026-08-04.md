### 2. 华为诺亚开源 MindMemOS：把"记忆"拆成 Agent 独立操作系统，LoCoMo 94.03 分

- **事件内容**：8 月 3 日，华为诺亚方舟实验室推出面向 AI Agent 的可迁移、自演进记忆操作层 MindMemOS，并采用 MIT 协议全量开源（GitHub：mindscale-noah/MindMemOS）。系统采用"实体-属性-时间"三维记忆建模，叠加 MindVanilla / MindSchema 双生成路径、Compact Search 多路径检索、离线 Dreaming 巩固、显隐式 Feedback、MindEvolve Skill 演进五大模块。在 LoCoMo 基准上 Overall Accuracy 达到 94.03、PersonaMem 上 MindSchema 达到 70.63%；在 400 个真实表格任务的 SpreadsheetBench-Verified 上，MindEvolve 监督演进将准确率从 No-skill 基线的 51.3% 提升到 57.2%。同步落地的还有自动算法设计平台 LLM4AD_Next。
- **为何值得关注**：当所有 Agent 框架都在卷上下文长度与工具调用次数时，华为诺亚把"记忆"从 Agent 内部的一个缓存类型提升为可独立部署、跨框架复用的"操作层"——这意味着 AI Coding Agent 在长程任务（多日 PR 维护、跨项目重构、企业 SOP 落地）上的"健忘"问题，第一次有了开源的基础设施级解法，对 Cursor、Claude Code、Devin、Cline 等主流编程 Agent 是直接的底层利好。
