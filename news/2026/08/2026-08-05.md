## 一、AI Coding（5 条）

### 1. Claude Fable 5 登顶 MirrorCode 编程榜：64% 绝对成功率，三倍碾压 GPT-5.6 Sol 21%

- **事件内容**：8 月 5 日，钛媒体援引 MirrorCode 编程智能体排行榜最新一期数据：Claude Fable 5 以 64% 的绝对生成成功率位列总榜第一，约为第二名 GPT-5.6 Sol（21%）的三倍；在 Ada、COBOL、Haskell 等语料稀缺的传统强类型语言上，Fable 5 的成功率仅下降约 3 个百分点，被认为已"摆脱语料牵引"，真正具备从零构建完整软件项目的能力。同日，AI 投资人 Matt Shumer 用三段提示词让 Claude Opus 5 从零生成 5.5 万行代码的 3D 射击游戏，并在购物车代码任务中一次性找出 6 个 bug 与 1 处浮点精度问题——证明在砍掉 80% 系统提示词后，Opus 5 反而更强。
- **为何值得关注**：编程 Agent 的"基准 + 语料鲁棒性 + 真实项目可交付"三件事第一次在同一天被同时跑通：Fable 5 拿下绝对值第一，Opus 5 在零工具场景下展示了"提示词精简→能力反升"的反直觉结论，GPT-5.6 则被拉开 3 倍差距。这意味着 AI Coding 工具栈的底层模型选型在 8 月进入"以 Claude 系为锚"的新阶段，Cursor、Cline、Devin 等产品对 Anthropic API 的依赖度会被进一步推高。
- **数据来源**：钛媒体 TAIFT《刚刚！Claude Fable 5，又拿第一了》2026-08-05；钛媒体 TAIFT《禁掉所有工具后，Opus 5 和 GPT-5.6 的差距终于藏不住了》2026-08-05。[¹]

### 2. 实在智能"实在 Agent"问鼎 OSWorld 全球榜首：90.20% 执行成功率，智能体首次破 90%

- **事件内容**：8 月 5 日行业榜显示，浙江实在智能推出的"实在 Agent"在 OSWorld 基准测试中以 90.20% 的执行成功率位列智能体框架与总榜双第一，这也是 OSWorld 自发布以来智能体成功率首次突破 90% 阈值。OSWorld 覆盖 300+ 真实桌面与网页任务、采用基于执行结果的自动验证，人类操作者平均成功率约 72%。实在 Agent 采用"通用模型 + Harness 工程"路径，核心能力来自复杂任务拆解调度、自我纠错与多智能体协同。
- **为何值得关注**：90% 是 Agent 行业普遍认可的"走出实验室"分水岭——越过这一阈值，桌面 / 浏览器 / IDE 内的 Agent 才开始具备"可验收、可计费"的工程化能力。结合 Cloudflare 当日同步推出的 Agent Development Lifecycle 与基于 OpenTelemetry 的追踪能力，"模型层 + 部署层 + 可观测层"三件套首次在国产阵营里凑齐，AI Coding Agent 的企业落地进入新阶段。
- **数据来源**：今日头条《实在智能"实在 Agent"问鼎 OSWorld 全球榜首，成功率首破 90%》2026-08-03 转 8-5 行业扩散；CSDN AI Agent 技术社区整理。[²]

### 3. DeepSeek 低价风暴打服硅谷：海外平台争相"倒贴" V4 Flash，DeepSeek Code 编程工具即将上线

- **事件内容**：8 月 5 日，量子位 QbitAI 头条披露：DeepSeek V4 Flash 以"3D 游戏 7 分钱/次、CS 对战 5 毛钱/把"级别的极低定价横扫海外 API 渠道，多家海外模型分发平台开始主动补贴 V4 Flash、靠 DeepSeek 流量带动自家订阅。性能侧，V4 Flash 在 DeepSWE 编程基准上从 7.3 飙至 54.4，逼近闭源顶级水平。官方同时确认，DeepSeek Code（对标 Cursor / Claude Code 的 IDE 级编程工具）即将上线；据开发者社区测算，每月 30 元即可让 AI 包揽脏活累活。
- **为何值得关注**：当 OpenAI 已在 7 月底被迫"防御性降价" 80%、Anthropic 8-5 又靠 Fable 5 拿下编程榜第一时，DeepSeek 选择走第三条路——"用极致低价 + 自家 IDE"在 AI Coding 工具链上从下往上拱。V4 Flash + DeepSeek Code 的组合一旦落地，将直接重写 100 美元/月以下 Cursor / Copilot 档位的成本结构，国内中文 IDE 工具栈（Trae、CodeBuddy、通义灵码）也将面临新一轮价格战。
- **数据来源**：量子位 QbitAI《DeepSeek 低价风暴打服硅谷！海外平台争相倒贴 V4 Flash》2026-08-05；AITNT 日报 8-5 同源转载。[³]

### 4. 面壁智能联合 OpenBMB 开源 ForgeStencil：双 Agent 一周自动优化 100+ 工业软件，全程 0 人工

- **事件内容**：8 月 5 日，面壁智能联合 OpenBMB 开源社区发布全球首个 Stencil（模板/算子）优化 AI 系统 ForgeStencil。系统由两个 Agent 驱动，1 周内自动完成 100+ 工业软件算子优化，全程 0 人工介入；同精度下获得 2.35× 平均加速，其中 CAE 求解器 hypre 达 3.86× 加速、电磁仿真 FDTD 达 2.47× 加速。ForgeStencil 通过 Agent 自动读取源码、构建测试、生成优化 stencil 并验证，号称打破"国产工业软件卡脖子的核心瓶颈——HPC 专家依赖"。
- **为何值得关注**：当所有人都在卷"模型更大、Agent 更通用"时，ForgeStencil 把 Agent 推进到"国产工业软件内核优化"这一被忽视的硬科技深水区。它意味着国产 CAD/CAE/EDA 工具链第一次有了一条"无需顶尖 HPC 专家也能持续迭代"的工程化路径，叠加全国产 EDA 攻坚节奏，AI Coding 的边界正从"写业务代码"扩展到"改编译器、优化数学库、重写物理求解器"。
- **数据来源**：面壁智能 / OpenBMB 官方公告，转引自 AITNT 日报 2026-08-05。[⁴]

### 5. LlamaFactory 作者郑耀威开源 PenguinHarness：0.2 元自动造 Agent，准确率 50%→90%

- **事件内容**：8 月 5 日，国产开源 LLM 微调框架 LlamaFactory 作者郑耀威发布全新项目 PenguinHarness，主打"全球首个支持多 Agent 自进化的 Harness"。通过自我博弈式训练，PenguinHarness 可在 0.2 元人民币成本下自动构建一个垂直 Agent，并将其在目标基准上的准确率从 50% 提升到 90%；系统支持 1000+ 模型，单次构造 Agent 的成本约为 Codex 的 1/200。
- **为何值得关注**：当 Anthropic、OpenAI 还在卖"模型席位"时，Harness 层正在被国产开源重新定义为"造 Agent 的乐高"——Harness 决定了 Agent 的工具调用策略、记忆管理与纠错逻辑，是把"模型能力"翻译成"任务完成率"的关键中间层。PenguinHarness 把"造 Agent"的边际成本压到 0.2 元，意味着接下来 3-6 个月会出现大量"针对单一企业内部流程"的垂类 Agent 自助生产线，企业级 AI Coding 工具的供给曲线将被显著拉平。
- **数据来源**：AITNT 日报《能让 DeepSeek 自进化的 Harness！LlamaFactory 作者开源新工具：0.2 元自动造 Agent》2026-08-05。[⁵]
