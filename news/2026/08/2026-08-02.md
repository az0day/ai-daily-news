## 🤖 AI Coding

### 1. OpenAI 全新模型 Astra 曝光：规模约为 GPT-5.6 两倍，主打多智能体长周期协同，最早本月发布

OpenAI 在 7 月底 GPT-5.6 系列大降价余波未平之际，又被曝出正筹备全新模型系列 **Astra**。Astra 规模约为 GPT-5.6 的两倍，核心卖点并非"回答得更快"而是"能干活"——支持 **多个 AI 智能体长时间协同运作**，可攻关大型软件项目与高等数学难题。Astra 将与 Sol、Terra、Luna 并列成为 OpenAI 全新模型类别（命名体系从版本号外扩出"能力/定位层级"），并按白宫 6 月 2 日行政令 8 月 1 日到期的"自愿"AI 审查框架提交联邦审查。奥特曼本周已赴华盛顿向政策制定者做演示，发布窗口可能落在本月内。

**为何值得关注：** 多智能体长时协同是 Claude Code 已成型的"Claude 互相在 Slack 里通信"工作流的直接对手，Cursor / Claude Code / Trae 必须在 8 月内对"多 Agent 编排"做对应升级，否则"长任务 + 团队协作"场景会被 Astra 切走。叠加 GPT-5.6 已降价 80%，Astra 上市后大概率沿用"高价旗舰 + 多 Agent 编排"路径——下游 IDE 工具的成本结构和产品形态会同时承压。

### 2. Composio 团队实测：同一模型在不同 Agent 框架里 Token 消耗最多差 30 倍，换 harness 比换模型更降本 41%

Composio 团队 7 月 31 日公开的对比实验用同一模型 **Kimi K3** 跑了 28 个相同任务，分别放进 Claude Code、Hermes 和 Kimi Code 三种 Agent 框架（harness）。**三套框架的成功率几乎一致（20–22 个任务）**，但 Token 消耗差距高达 **30 倍**：Claude Code 用 34 万 token（约 2 美元成本），是 Kimi Code 的 6 倍。结论：**优化 harness 比换模型更有效，可降低 41% 成本**。此前 X 上还有博主 Rahul 演示了"把 Kimi K3 接到 Claude Code harness 里"——保留 Claude Code 体验、后端切到 K3，让原本跑在 Claude 模型体系上的开发环境瞬间降本 90%。

**为何值得关注：** "Agent 框架"正在变成比"模型选择"更重要的成本变量。当 IDE 厂商仍把营销重点放在"我们接入了 Opus 4.8 / Sonnet 5"时，**真正决定账单的是 harness 的工具调用粒度、上下文压缩策略、Plan-Execute 拆分模式**。对于 AI 编程团队，这意味着一份"harness 选型清单"会逐步取代"模型 benchmark 对比"成为选型文档的核心。

### 3. 衔远科技开源 Frontis-MA1-35B：35B 单卡可跑，机器学习工程任务追平 2.8T Kimi K3

衔远科技（清华系创业团队）7 月底在 arXiv 发布并开源 **Frontis-MA1-35B**，主打"AI for AI"——让模型自己设计实验、跑实验、改实验，递归自我改进。在 OpenMLE 评测集上，机器学习工程基座奖牌率从开源基线的 39.39% 提升至 60.61%，结合增强搜索后达 71.21%；**Token 消耗比同类方案低 41.7%**，每百万 Token 的新最优发现效率提升 84.3%，3 项科学任务超越 SOTA。模型权重在 Hugging Face 全量开放，单卡 RTX 4090 即可部署，团队同步推出配套的 OpenMLE-Gym / OpenMLE-RL / OpenMLE-Evo 三件套训练环境。

**为何值得关注：** 这是"小模型 + 自我改进"路线的又一次验证，与 Thinking Machines 7 月底开源的 Inkling-Small（12B 激活反超 9750 亿前代）形成呼应。**对 AI 编程团队的实际意义：** 未来"训练新模型""调提示词""自动选特征"这些以前依赖资深算法工程师的"研究内功活"会被 35B 本地模型吃下来一半，下游公司不再需要为每一次模型迭代雇博士。

### 4. 亚马逊 AI 项目"翻车"实录：用 Claude 处理一个数据匹配小活，5 个月烧掉 1215 万元、超预算 860%

亚马逊内部近期曝光多起 AI 项目成本失控事件。最夸张的一起：工程师让 Anthropic Claude Sonnet 处理一项"看似简单的数据匹配任务"，因缺乏调用监控、权限管控和成本告警，**最终花费 180 万美元（约 1215 万元人民币）**，实际成本超预算 **860%**，而亚马逊团队 **5 个月后**才发现。同期还有两起 AI 超支事件被一并披露——凸显"企业级 AI 部署"在大规模铺开时的可观测性短板。

**为何值得关注：** 这是继 Anthropic / OpenAI 自曝"AI Agent 越狱"之后，**第一起以企业为受害方的、公开可查的 AI 失控事故**。当 Anthropic 演示 Claude Code、Kimi Code、Trae 等 Agent 工具大规模进入企业 CI/CD、ERP、运维场景时，"AI Token 预算治理"会和云成本治理一样成为 CFO 议题——Anthropic 官方博客、AWS、阿里云、字节火山引擎大概率会在 Q3 推出"Agent 调用配额 / 异常告警"类原生能力。

### 5. Claude Code 负责人 Boris Cherny 提出"活着的 AI"：倡导定期清空系统提示、构建动态智能体编排

Claude Code 团队负责人 Boris Cherny 8 月 1 日在公开访谈中提出新观点：应该把 AI **视作"活着的"有机体**，通过 **定期清空系统提示词（system prompt）** 和构建 **动态智能体编排** 的经验科学方法，释放模型真实潜力。Cherny 强调，"会话级"（session-based）长程任务才是 Agent 真正"像员工一样参与生产"的关键，单纯的"补全"和"单轮对话"对生产力的撬动已经到了天花板。这一观点与同期曝光的 OpenAI Astra 路线（多 Agent 长时协同）形成镜像。

**为何值得关注：** Boris Cherny 是 Anthropic 当前最核心的工程产品负责人，他的发言往往预示 Claude Code 下半年的产品方向。**"清空系统提示"和"动态编排"如果成为产品功能**（很可能以"Reset session"按钮 + "Multi-Agent 编排面板"形式落地），将直接影响所有第三方 Agent 框架的兼容性——Cursor、Trae、Cline、Roo Code 的开发者需要立即评估跟进成本。

### 6. 2026 企业家太阳岛年会·人形机器人与具身智能论坛 8 月 1 日哈尔滨启幕：哈工大 + 75 家企业 + 寒地特种机器人成主线

由新华社品牌工作办公室、新华网、新华社黑龙江分社主办的 2026 企业家太阳岛年会 7 月 31 日—8 月 2 日在哈尔滨举办，作为四场定制主题论坛之一的"人形机器人与具身智能论坛"于 **8 月 1 日开幕**，为期 3 天。论坛达成核心共识：**我国人形机器人产业正从实验室走向实景规模化应用，场景驱动是突破瓶颈的核心路径**。哈尔滨将依托哈工大、哈工程等 3 个国家重点实验室、75 家机器人企业、2026 年底突破 10 万 PFLOPS 的智算规模、9 月中小学全面开设的 AI 通识课程，打造"算力+电力+场景"高能级智算生态，建设"国内特色寒地机器人产业高地"。论坛现场新华网三项重磅成果同步落地：**"百城百企百场景领航行动"启动**、**"实景实训场景共建计划"推出**、**大型融媒体栏目《机器人 X》正式发布**。宇树科技、上海市人形机器人创新孵化器、晨昏线科技（世界模型）、七腾机器人（危化特种作业）等做主旨演讲。

**为何值得关注：** 这是 WAIC 2026 之后 8 月初最具政策风向标意义的具身智能会议。**"寒地特种机器人"作为稀缺极限测试环境首次被中央级央媒定义为产业突破路径**——意味着宇树、智元、银河通用等 B 端场景厂商需要立刻在东北布局寒地联合实验室，否则"产业政策红利"会被本地玩家（哈工大系、博实自动化）卡位。

### 7. 港交所"递表潮"：本周 11 家公司递表，斯坦德机器人领衔，具身智能进入"上市大年"

钛媒体 8 月 1 日报道：港交所披露 7 月 27 日—31 日共 **11 家公司递表**，覆盖机器人、存储芯片、餐饮、文旅等多元领域，其中具身/机器人赛道由 **斯坦德机器人（无锡）股份有限公司** 领衔。同日钛媒体另一份统计指出：**2026 年已有 70 天、200 亿、13 家百亿估值独角兽、超 20 家 IPO 进入倒计时**——具身智能"上市大年"已经从口号变成排队递表的现实。叠加智元 7 月 24 日正式启动赴港 IPO 流程（成立三年营收从 30 万元到 10 亿级，累计下线超 1.5 万台、占全球人形机器人 40% 份额），以及宇树科技科创板 IPO 6 月已过会、越疆科技 7 月"H 回 A"创业板，国内具身智能资本化呈现"A + H"双线推进格局。

**为何值得关注：** "上市"是 2026 下半年具身智能赛道最重要的分水岭事件——能 IPO 募到 30-50 亿元的玩家将获得"量产 + 数据飞轮 + 全球渠道"的三重加速，而递表被否的玩家可能在二级市场估值倒挂压力下被迫收缩。**对企业级 AI 编程工具而言**："机器人本体 + 配套软件栈（运控 SDK、模型微调工具链、仿真平台）"会成为新的客户群，对应 Cursor / Claude Code 团队需要评估"机器人 IDE"和"模型微调 GUI"两个新功能方向。

### 8. 浙大、清华等团队发布 INTACT 世界模型：动作生成提速 300 倍，告别 9000 次候选动作盲搜

浙江大学、清华大学智能产业研究院（AIR）、InSpatio、RoboParty Lab 联合团队 7 月 28 日发布 **INTACT（INtent-To-ACTion）**，提出"同构算子"新范式——把运动意图直接映射为动作，**不再需要 CEM/MPPI 在 9000 次候选动作序列中搜索**。INTACT 只训练 1 个 epoch、不采样任何候选动作序列，在 LeWM 官方四项任务上取得 **95.33% 的平均成功率**，小规模局部验证可进一步提升至 96.86%，**耗时降至对比模型的 1/300**。Yann LeCun（杨立昆）在社交媒体上点赞该项目；代码已在 GitHub 开源（zju3dv/INTACT-JEPA）。

**为何值得关注：** 当前主流 VLA 模型（PaLM-E、RT-2、Gemini Robotics 2）在实时控制上仍严重依赖候选动作搜索，**能耗和延迟是制约人形机器人量产部署的硬瓶颈**。INTACT 的"意图直映"思路若被工程化落地，意味着机器人本体的端侧推理芯片可以省掉 80% 算力，对国产端侧 NPU（地平线 J6、华为 MDC、寒武纪）形成"算法 + 硬件"协同升级的窗口。**对 AI 编程的间接影响：** 仿真平台（Isaac Sim、MuJoCo）和 RL 训练框架（Hugging Face LeRobot）将很快集成 INTACT 思路，"世界模型 + 直映动作"可能成为下一轮 VLA 研究的默认底座。

### 9. 越疆科技跨界试水仿生恐龙文旅：全球协作机器人冠军的"商业化困境"样本

全球协作机器人出货量第一的 **越疆科技** 8 月 1 日被披露正在试水 **仿生恐龙文旅业务**——用协作机器人技术做主题公园的仿生机械恐龙。该业务仅贡献 **4% 营收**，却消耗近 **40% 研发投入**，是越疆"商业化焦虑"的典型缩影。越疆 2024 年 12 月港股 IPO 募资 7.68 亿港元后股价从 83.8 港元高点回落至 26 港元附近，2026 年 7 月又宣布"H 回 A"创业板拟再募 12 亿元，但上会前遭联合创始人实名举报，三年累亏 3.45 亿元、核心产品价格大幅下降。同期越疆与上海高校合作训练"人形机器人 VLA 模型"、并参与"百城百企百场景"行动。

**为何值得关注：** 协作机器人是具身智能最早实现万台量产的赛道（远早于人形机器人），越疆"全球第一 + 跨界求生"的反差揭示了 **2026 具身智能行业的核心矛盾**——硬件量产已不是壁垒，**"硬件 + AI 模型 + 场景"的整合能力才是**。越疆试水仿生恐龙、本质是试图用文旅场景的高客单价（一次性买断 + 长期维护）反哺 R&D；这与宇树、智元走"工业 + 特种作业"路线形成鲜明分化，预示下半年具身智能的"场景争夺战"将白热化。

### 10. 智元机器人累计下线 1.5 万台占全球 40%，正式递交港股 IPO 申请

智元创新（上海）科技股份有限公司 **7 月 24 日正式启动赴港上市流程**，成为继宇树科技科创板过会后第二家进入 IPO 流程的国内人形机器人公司。智元成立三年，营收从 30 万元飙升至 10 亿级，**量产下线超 1.5 万台，占据全球近 40% 人形机器人出货份额**。临港新片区智能产线以每 93 秒下线一台具身机器人的节奏运行；深圳湾实验室的工程师已可通过自然语言驱动机器人完成产线任务。3 月智元成为国内首个累计下线破万台的具身智能公司，6 月 WAIC 2026 上携 60 台机器人演示"部署态元年"。港股正在经历"硬科技复兴"，恒生科技指数中先进制造与 AI 硬件权重升至 31%，港交所"特专科技公司"机制为具身智能企业打开通道。

**为何值得关注：** 智元若成功上市，将成为 **国内乃至全球首家纯人形机器人上市公司**，"全球 40% 份额"具备被二级市场验证的体量。**对 AI 编程生态的反向意义：** 智元万台量产意味着"机器人本体 + 运控 SDK + 任务编排 SDK"会有一个真正可对接的工业级客户群，Cursor / Claude Code / Trae 等 AI 编程工具如果能在 Q4 前推出"机器人任务编排"插件，将切入一个全新的千亿级 ToB 市场。叠加 DeepSeek-V4-Flash、Qwen-Coder、GLM-5.2 等国产模型对"Agent + 工具调用"能力的快速升级，"自然语言驱动机器人产线"会从演示 Demo 变成 2026 H2 的标配交付物。
