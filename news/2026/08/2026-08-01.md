## 🤖 AI Coding

### 1. Anthropic 发布 MCP 2026-07-28 规范，AI Agent 协议迈入"生产级"

Anthropic 正式发布 Model Context Protocol 2026-07-28 规范，关键变化包括：引入 **Stateless Core**，MCP 服务器可直接部署到 serverless/edge 基础设施，水平扩展能力大幅提升；认证机制与 **OAuth 2.0 / OIDC** 标准对齐，可直接对接 Entra、Okta 等企业身份系统；MCP Apps 和 Tasks 纳入版本化扩展框架，开发者无需改动核心协议即可扩展 UI 与长时任务能力。Claude 连接器目录已收录超 950 个 MCP 服务器，月 SDK 下载量突破 4 亿次。

**为何值得关注：** MCP 正在成为 AI Agent 时代的"HTTP 协议"。此次升级同时解决了可扩展性、开发者扩展性、企业合规三大瓶颈，Cursor、Claude Code、Trae 等编程工具的工具生态扩张将显著加速，AI 编程 Agent 也将更易进入金融、医疗、政府等强合规场景。

### 2. DeepSeek-V4-Flash 正式版 API 上线公测，智能体能力反超 V4-Pro 预览版

DeepSeek 于 7 月 31 日发布 V4-Flash 正式版 API（V4-Flash-0731），模型结构与尺寸与 preview 一致，仅重新完成后训练，但 Agent 能力大幅增强，多项智能体基准测试结果远超 V4-Pro-Preview 预览版。社区反馈其表现已逼近 Claude Opus 4.8，被认为是 DeepSeek 对 OpenAI 下调 GPT-5.6 Luna / Terra 价格的快速性价比回应。V4-Pro 正式版也已进入"尽快发布"阶段。

**为何值得关注：** 在 GPT-5.6 Luna 大幅降价的背景下，国产模型仍以"Flash 档位逼近 Pro 性能"的策略贴身竞争，AI 编程 API 价格战进入白热化阶段；同时 DeepSeek 正在从"通用大模型"向"AI 编程基础设施"战略转身。

## 🦾 具身智能

### 3. 谷歌 DeepMind 发布 Gemini Robotics ER 2，连续视频理解 + 多机器人协作

谷歌 DeepMind 于 7 月 30 日推出 Gemini Robotics ER 2（Embodied Reasoning 2），定位为机器人的"高级大脑"。相比 1.6 版本，ER 2 可分析连续视频流，机器人能够跟踪自身任务进度、在动作出错时调整重试，并判断何时进入下一步骤；可原生调用 Google Search 或开发者自定义函数；接入 Gemini Live API 双向流式端点，显著降低传统"停止—思考—再行动"的停顿。任务进度分类准确率 57.4%，moment-finding 关键时刻定位准确率 91.3%（平均绝对时间误差 0.96 秒），执行速度为同档位大模型的 4 倍。ER 2 还支持多机器人协作，演示了 Apptronik Apollo 2 与 Franka FR3 Duo 跨厂商机器人协同完成复杂工作流。已通过 Gemini API 与 Google AI Studio 公开，Gemini Enterprise Agent Platform 开启私密预览。

**为何值得关注：** VLA（视觉-语言-动作）模型正从"单机器人理解物理世界"演化为"多机器人协同 + 实时推理"。ER 2 的"高级大脑 + 低层级 VLA 执行"分层架构，可能成为下一代具身智能系统的标准范式，直接影响国内银河通用、智平方、宇树等厂商的模型路线选择。

### 4. 央视报道：杭州具身智能产业汇聚 700+ 企业、产值超千亿，作业场景直接搬进训练区

央视新闻 7 月 31 日报道，浙江杭州已汇聚 700 余家具身智能企业，相关产值规模超过千亿。"活力中国调研行"探访杭州具身智能展示与应用推广中心，核心做法是**把工业/物流等真实作业场景直接搬进训练区**，让模型在仿真—现实之间闭环迭代，加速从演示到产线的迁移。同期，《杭州市具身智能机器人"强链补链"行动方案（2026-2027 年）》进入落地阶段，重点补齐减速器、伺服电机、力矩传感器等核心零部件短板。

**为何值得关注：** 具身智能竞争的焦点正从"机器人本体的运动能力"转向"训练场与真实场景的差距（sim-to-real gap）"。杭州作为产业重镇，把真实作业场景前置到训练阶段的方法论，可能成为继"造一台机器人"之后的新产业分水岭。

### 5. 2026 企业家太阳岛年会·人形机器人与具身智能论坛（8 月 1 日，哈尔滨）启幕

由新华社品牌工作办公室、新华网、新华社黑龙江分社等主办的人形机器人与具身智能论坛，于 8 月 1 日在哈尔滨"2026 企业家太阳岛年会"期间启幕，为期 3 天。论坛汇聚国家相关产业部门、央企、整车与机器人企业及科研机构，重点议程包括具身智能产业政策、VLA 与世界模型、人形机器人量产与商业化路径、跨场景应用与投融资趋势。

**为何值得关注：** 在 WAIC 2026 之后，哈尔滨论坛是 8 月初国家级别的另一场产业风向标会议，可能释放新一轮具身智能产业政策与重大项目信号；东北老工业基地的机器人产业升级路径也将得到集中讨论。
